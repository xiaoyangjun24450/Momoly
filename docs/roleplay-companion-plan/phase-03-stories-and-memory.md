# 阶段 3：线下故事与共享记忆

前置阶段：[阶段 2](phase-02-world-time-and-travel.md) 验收通过。  
状态：计划，尚未实现和验收。  
关联：[总计划与统一验收素材](README.md)、[产品需求](../roleplay-companion-requirements.md)。

## 1. 阶段目标和可视化结果

完成“线上聊天约定—出行赴约—单人或多人线下故事—回到聊天仍记得共同经历”的完整流程。

完成后应能看到：聊天中的赴约按钮、独立故事页面、场景和参与者、明确标注的角色发言与动作、可选行动、自由输入区、结束或继续故事的入口，以及故事期间无法切换世界的提示。

## 2. 功能模块

### 2.1 线下意图与赴约入口（模块 6、11）

- 输入：聊天上下文、涉及的角色和地点、当前世界与日程、用户是否点击赴约。
- 输出：赴约按钮及其目标地点和角色信息；点击后交给出行或故事模块的请求。
- 具体功能：识别对话中实际出现的见面、一起吃饭等线下意图；给出明确按钮；由用户点击后进入流程。跨地点先移动，角色能否参与由位置和日程决定。
- 例子：用户与林夏约好 09:00 在图书馆见面，聊天显示“前往图书馆”。用户在家点击后选择出行方式，到达并满足见面条件后进入故事，不直接跳过路程。

### 2.2 故事界面与行动推进（模块 7、11）

- 输入：世界、场景、参与角色、相关记忆、故事当前进度、用户选择或自由输入的行动。
- 输出：场景叙述、角色动作和对话、后续行动选项、故事进度和实际发生的事件。
- 具体功能：提供独立的文字游戏界面；同时支持选项与自由输入；角色响应与场景、当前状态和记忆一致；只有已发生的行动进入事件和记忆，尚未点击的选项不能当作已发生。
- 模式边界：线下故事允许动作、场景和旁白；切回线上聊天时，重新使用阶段 1 的活人感与纯消息规则，不能把故事叙述直接放进聊天气泡。
- 例子：页面给出“把书递给林夏”和“先找位置坐下”两个选项。用户也可以输入“我拿出红色封面的书，问她想不想借回去看”，故事依据实际输入继续。

### 2.3 多角色共同参与（模块 7、5）

- 输入：同一世界、同一场景中符合参与条件的角色及各自状态，当前故事事件。
- 输出：参与者列表、区分角色的发言和行动、每个角色实际获知的信息。
- 具体功能：先跑通单角色故事，再在本阶段内扩展为多人；区分谁说了什么、谁做了什么以及谁目睹了事件；参与状态与角色日程、位置保持一致。
- 例子：林夏接过书，沈言在旁边说“看完也借我看看”。两段发言分别标注角色；仍在家的周宁没有出现在场景中，也没有因此获得借书记忆。

### 2.4 线上与线下共享记忆（模块 8、11）

- 输入：已保存的聊天和已发生的故事事件、世界和游戏时间、参与及知情角色、记忆查询请求。
- 输出：每个角色的经历、已知事实、约定和关系变化，以及供后续生成使用的相关记忆与摘要。
- 具体功能：线上约定进入线下上下文，线下经历进入后续聊天上下文；按角色的知情范围保存和读取；复用现有摘要能力，并把适用范围从单一会话扩展到角色跨互动方式的记忆。
- 例子：聊天时说要带红色封面的书，见面时林夏记得这件事。借书完成后回到聊天，林夏知道书在自己手里，沈言知道发生过借书，周宁不能凭空描述这件私人经历。

### 2.5 场景互斥、故事结束与继续（模块 3、5、6、7）

- 输入：线下故事开始、推进和结束状态；当前同场景角色；切换世界或返回聊天的请求；已保存故事。
- 输出：同场景角色的聊天回复限制、世界切换结果、恢复后的故事进度和结束后的角色状态。
- 具体功能：线下互动期间，同场景角色的回应发生在故事中，暂停聊天窗口回复；其他世界仍然冻结。故事进行期间禁止快穿，必须结束故事后再切换。离开故事页面或重新打开 APP 不等于结束故事。
- 例子：用户与林夏和沈言在图书馆互动，尝试切换奇幻世界时提示先结束故事。结束后可以快穿，校园世界随之冻结；返回后仍保留借书记忆。

## 3. 阶段内执行顺序

1. 建立聊天和故事共同使用的角色记忆读写能力。
2. 跑通单角色的赴约、出行衔接、故事开始和结束。
3. 完成选项与自由输入、角色状态互斥和禁止快穿。
4. 在同一故事能力上加入多人参与和按角色区分的知情范围。
5. 完成故事恢复，执行从线上到线下再回线上的完整验收。

本阶段不以静态叙述页面或只存一份全员共享摘要作为完成标准。

## 4. 完成后如何验收

准备：使用统一借书事件。把角色推进到可在图书馆见面的时段，分别执行单角色和多人用例；周宁保持不在场且未被告知。

| 编号 | 操作步骤 | 应看到的结果与通过标准 |
| --- | --- | --- |
| P3-01 | 与林夏约定在图书馆见面并带书。 | 聊天出现与实际约定对应的赴约按钮，地点和角色正确；未点击时不会自动移动。 |
| P3-02 | 在家点击赴约并选择出行方式。 | 进入现有移动流程，消耗正确游戏时间后到达；没有跳过行程或把角色瞬移到场。 |
| P3-03 | 到达后开始单角色故事。 | 显示图书馆场景、林夏及面对面对话；线上约定的书进入故事上下文。 |
| P3-04 | 先选择一个行动选项，再自由输入另一个行动。 | 两种输入都推进同一段故事；未选择的行动不进入已发生事件。 |
| P3-05 | 让林夏与沈言共同参与借书故事。 | 两名角色的发言和动作可辨认，参与者位置和状态与场景一致。 |
| P3-06 | 故事进行中查看聊天，并尝试切换世界。 | 同场景角色不在聊天窗口同时回复；切换世界被阻止，且当前世界没有变化。 |
| P3-07 | 在故事中途离开页面、关闭并重新打开 APP。 | 能恢复故事，参与角色和进度正确；仍不能通过重新打开 APP 绕过快穿限制。 |
| P3-08 | 完成借书并结束故事，分别与林夏、沈言聊天。 | 林夏记得自己借到了书；沈言记得自己看到的经过；线上只显示他们发来的消息，不能延续动作或旁白叙述；事实不能互相矛盾。 |
| P3-09 | 在未透露借书事件的前提下，与周宁进行普通聊天。 | 周宁不会主动准确复述未获知的私人借书经过；验收时避免把答案写在提问中。 |
| P3-10 | 结束故事后切换奇幻世界，再返回校园世界。 | 故事结束后允许快穿；冻结和恢复正常；关系、聊天和借书记忆仍在。 |
| P3-11 | 检查参与角色的会话列表。 | 每个角色仍只有一个聊天会话，线下故事没有额外生成第二个聊天会话。 |

## 5. 验收交付物

- 赴约按钮、单角色故事、多人发言、选项与输入区、禁止快穿提示的截图。
- “约定—出行—借书—结束故事—聊天回忆”的完整录屏。
- 各角色记忆检索的验收记录，用于对照实际知情范围；普通用户流程不需要展示内部提示词。
- P3-01 至 P3-11 的实际结果、故事恢复结果和前两阶段关键路径回归结果。

通过条件：单人和多人故事均可操作，线上线下记忆互通且区分角色，故事状态能持续约束聊天和世界切换。此时可以开始阶段 4。
