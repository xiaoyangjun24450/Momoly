## 1. 阶段目标

### 1.1 目标

跑通"线上聊天约定—出行赴约—单人或多人线下故事—回到聊天仍记得共同经历"的完整流程。前置条件是阶段 2 验收通过：世界、游戏时间、地图与角色日程已可观察、可保存。2026-11-04 调整：用户出行从阶段 2 后移，需在本阶段赴约前完成，具体设计与验收用例待补；不能再假定阶段 2 已交付用户移动。

本阶段交付的是**有状态的故事**：故事有参与角色、场景、已发生事件和可恢复的进度；故事期间与结束后，聊天、世界切换、角色记忆都必须服从同一份状态，而不是各自独立的一套界面。

### 1.2 完成后可体验的结果

| 可体验结果 | 说明 |
| --- | --- |
| 赴约按钮 | 聊天里出现与实际约定对应的"赴约/前往某地点"按钮，标注目标地点和角色；不点击不会自动移动。 |
| 独立故事页面 | 全屏文字游戏界面，显示场景、参与角色、面对面对话与动作。 |
| 两种行动方式 | 既能点选预设行动，也能自由输入行动或对话，同一回合内推进同一段故事。 |
| 多人同场 | 同一世界的多个角色出现在同一场景，发言和动作可辨认，各自只知道自己实际获知的经过。 |
| 结束与继续入口 | 故事可暂停、可恢复、可结束；离开页面或重开 APP 不视为结束。 |
| 状态约束提示 | 故事期间切换世界被阻止并给出提示；同场景角色不在聊天窗口同时回复。 |
| 回到聊天 | 故事结束后回到原聊天会话，角色带着共同经历说话，每角色仍只有一个会话。 |

### 1.3 完成边界

本阶段不以"静态叙述页面"或"只存一份全员共享摘要"作为完成标准；也不以页面能打开、截图好看代替状态与知情范围验收。

## 3. 功能需求

### 3.1 线下意图与赴约入口（模块 6、11）

| 编号 | 需求 | 边界与说明 |
| --- | --- | --- |
| R3-01 | 从聊天上下文识别实际出现的线下行为意图（见面、一起吃饭、去图书馆等）。 | 只在确有意图时出现入口；不因普通闲聊误报。判定方式由设计确定。 |
| R3-02 | 入口必须是对应本次约定的明确按钮，显示目标地点与涉及角色。 | 例："前往图书馆"。按钮不是自动执行。 |
| R3-03 | 由用户点击后才进入流程；跨地点先完成移动，不能跳过路程或把角色瞬移。 | 复用阶段 2 地图与耗时设定，用户出行流程在本阶段接入。 |
| R3-04 | 角色能否参与由位置和日程决定。 | 到点后不满足见面条件时，需有可解释的结果（继续等待、改约或无法见面），不能硬进入故事。 |

### 3.2 故事界面与行动推进（模块 7、11）

| 编号 | 需求 | 边界与说明 |
| --- | --- | --- |
| R3-05 | 提供独立的全屏故事界面，呈现场景叙述、角色动作与对话。 | 不复用聊天气泡形态承载旁白。 |
| R3-06 | 同时支持预设选项与自由输入，两种方式推进同一段故事。 | 自由输入不能被限制为只能选选项。 |
| R3-07 | 角色响应与场景、当前状态和记忆一致；不替用户行动、不凭空新增未出现角色。 | 场景内的路人/店员由旁白临时扮演，不建立角色卡。 |
| R3-08 | 只有实际发生的行动进入事件与记忆；未点击的选项不能当作已发生。 | 选项只是候选，不是事实。 |
| R3-09 | 故事内允许动作、场景与旁白；切回线上聊天重新遵守纯消息规则。 | 不能把故事叙述直接放进聊天气泡，见 §4。 |
| R3-10 | 生成失败或中断不能留下半截已发生事件。 | 失败可重试；恢复后不重复已提交回合。 |

### 3.3 多角色共同参与与知情范围（模块 7、5）

| 编号 | 需求 | 边界与说明 |
| --- | --- | --- |
| R3-11 | 先跑通单角色故事，再在本阶段内扩展为多人。 | 多人不是下一阶段的前置。 |
| R3-12 | 区分谁说了什么、谁做了什么、谁目睹了事件。 | 发言与动作按角色标注；旁白不等同于角色发言。 |
| R3-13 | 参与状态与角色日程、位置保持一致，避免同一角色同时出现在冲突场景。 | 参与者必须是到点后在同一场景、且状态允许的角色。 |
| R3-14 | 每个角色只获得自己实际获知的信息。 | 未在场且未被告知的角色不得获得该次私人经历，见 P3-09。 |

### 3.4 线上与线下共享记忆（模块 8、11）

| 编号 | 需求 | 边界与说明 |
| --- | --- | --- |
| R3-15 | 同一角色的线上聊天与线下互动共用持续记忆。 | 每个角色只有一个会话、一份持续记忆。 |
| R3-16 | 线上约定、交流与关系变化影响线下故事；线下事件、对话与关系变化影响后续聊天。 | 双向互通，不要求用户手动搬运。 |
| R3-17 | 记忆按角色的知情范围保存和读取。 | 借书事件只进入在场者记忆；周宁即使被提问也不能准确复述。 |
| R3-18 | 切换界面或地点、世界冻结与恢复都不清除记忆、聊天记录、关系或故事进度。 | 冻结只暂停时间与活动，不是清空。 |
| R3-19 | 复用现有摘要能力，但适用范围从单一会话扩展到角色的跨互动方式记忆。 | 实现方式见设计文档；不接受"只存一份全员共享摘要"。 |

### 3.5 场景互斥、故事结束与继续（模块 3、5、6、7）

| 编号 | 需求 | 边界与说明 |
| --- | --- | --- |
| R3-20 | 线下互动期间，与用户同场景的角色回应发生在故事中，暂停聊天窗口回复。 | 不同时两处回复；结束后是否回复由其日程和状态决定。 |
| R3-21 | 其他世界继续冻结；故事期间不会从聊天窗口收到其他世界消息。 | 与其他世界冻结规则一致。 |
| R3-22 | 故事进行期间禁止快穿，必须先结束当前故事；单人与多人故事同一规则。 | 尝试切换时被阻止且当前世界不变。 |
| R3-23 | 离开故事页面、切到后台或重新打开 APP 不等于结束故事；恢复后进度正确。 | 重开 APP 也不能绕过禁止快穿。 |
| R3-24 | 故事结束后允许快穿；原世界冻结、目标世界恢复；返回后故事记忆仍在。 | 与阶段 2 冻结恢复规则衔接。 |

## 4. 跨模块约束

| 约束 | 要求 | 关联用例 |
| --- | --- | --- |
| 线上纯消息 / 线下允许叙述 | 线上只显示角色实际发来的消息正文，不含动作、场景、旁白、内心独白；动作与场景只在故事界面出现。 | P3-08、阶段 1 回归 |
| 每个角色唯一会话 | 线下故事不新建第二个聊天会话；故事记录与聊天记录是同一角色的不同互动方式。 | P3-11 |
| 故事期间同场景角色暂停聊天回复 | 同场景角色不并行回复聊天；其他角色受各自日程与世界状态约束。 | P3-06 |
| 其他世界冻结 | 故事期间其他世界时间、日程与消息全部暂停。 | P3-06 |
| 禁止快穿 | 故事未结束时不能切换世界，离开页面或重开 APP 不解除。 | P3-06、P3-07 |
| 记忆不清除 | 冻结、切换、重开 APP、故事暂停都不清除共同经历与关系。 | P3-10 |
| 事实一致 | 角色记忆之间不能互相矛盾；未发生行动不进入记忆。 | P3-04、P3-08 |
| 状态唯一来源 | 位置、时间、故事状态、世界运行状态各只有一份事实来源，页面只是展示。 | P3-02、P3-07 |

## 5. 验收用例

### 5.1 验收准备

使用 [文档总览 §3](../README.md) 的统一素材：林夏、沈言、周宁在校园世界，奇幻世界为艾琳；按阶段 2 的日程把角色推进到可在图书馆见面的时段。分别执行单角色与多人用例；**周宁始终不在场且未被告知**。涉及生成内容的用例连接实际模型服务，措辞不要求逐字一致，但人物、事件、状态与知情范围必须符合用例。

### 5.2 用例表

| 编号 | 操作步骤 | 应看到的结果与通过标准 |
| --- | --- | --- |
| P3-01 | 与林夏约定在图书馆见面并带书。 | 聊天出现与实际约定对应的赴约按钮，地点和角色正确；未点击时不会自动移动。 |
| P3-02 | 在家点击赴约并选择出行方式。 | 进入现有移动流程，消耗正确游戏时间后到达；没有跳过行程或把角色瞬移到场。 |
| P3-03 | 到达后开始单角色故事。 | 显示图书馆场景、林夏及面对面对话；线上约定的书进入故事上下文。 |
| P3-04 | 先选择一个行动选项，再自由输入另一个行动。 | 两种输入都推进同一段故事；未选择的行动不进入已发生事件。 |
| P3-05 | 让林夏与沈言共同参与借书故事。 | 两名角色的发言和动作可辨认，参与者位置和状态与场景一致。 |
| P3-06 | 故事进行中查看聊天，并尝试切换世界。 | 同场景角色不在聊天窗口同时回复；切换世界被阻止，且当前世界没有变化。 |
| P3-07 | 在故事中途离开页面、关闭并重新打开 APP。 | 能恢复故事，参与角色和进度正确；仍不能通过重新打开 APP 绕过快穿限制。 |
| P3-08 | 完成借书并结束故事，分别与林夏、沈言聊天。 | 林夏记得自己借到了书；沈言记得自己看到的经过；线上只显示他们发来的消息，不能延续动作或旁白叙述；事实不能互相矛盾。 |
| P3-09 | 在未透露借书事件的前提下，与周宁进行普通聊天。 | 周宁不会主动准确复述未获知的私人借书经过；验收时避免把答案写在提问中。 |
| P3-10 | 结束故事后切换奇幻世界，再返回校园世界。 | 故事结束后允许快穿；冻结和恢复正常；关系、聊天和借书记忆仍在。 |
| P3-11 | 检查参与角色的会话列表。 | 每个角色仍只有一个聊天会话，线下故事没有额外生成第二个聊天会话。 |

### 5.3 通过标准

单人、多人故事均可操作；选项与自由输入都生效；线上线下记忆互通并按角色区分知情范围；故事状态持续约束聊天回复、世界切换与 APP 重开，且故事结束后约束解除。全部 P3-01 至 P3-11 按实际结果记录，未执行或失败项不能标为通过。
